    How the check works
    
        
    Four layers, cheapest first.
    
      
    
      
    
        
    
          
    
          
    
            
    1. Local rules
    
            
    Syntax, length, role accounts (info@, sales@), a built-in disposable list and a typo suggestion. No network call.
    
          
    
        
    
        
    
          
    
          
    
            
    2. DNS records
    
            
    MX lookup over DNS-over-HTTPS to Google, with Cloudflare as a fallback. Tells you whether the domain can receive mail.
    
          
    
        
    
        
    
          
    
          
    
            
    3. Reputation
    
            
    Disify, then UserCheck if needed, add throwaway/alias signals. Both are keyless and CORS enabled.
    
          
    
        
    
        
    
          
    
          
    
            
    4. Optional SMTP
    
            
    emailvalidation.io asks the mail server about the exact mailbox. It is the strongest signal and the only paid call.

    Limits and security
    
        
    Rate limiting, caching, and server-side key protection.
    
      
    
      
    
        
    
          
    
            
          
    
          
    Server proxy
    
          
    Deep mailbox checks go to POST /api/verify. The emailvalidation.io key lives in the server environment, not in this page.
    
        
    

        
    
          
    
            
          
    
          
    Rate limits
    
          
    The server enforces per-IP and daily caps for deep checks and contact. Browser limits are only courtesy guards.
    
        
    

        
    
          
    
            
          
    
          
    Timeouts
    
          
    Every request is aborted on timeout and falls back to the next provider or to an "unknown" result.
    
        
    

        
    
          
    
            
          
    
          
    Caching
    
          
    Reports are cached locally for 24 hours, so repeat checks cost no request and no credit.
    
        
    

        
    
          
    
            
          
    
          
    Output handling
    
          
    API text is inserted as text nodes, never as HTML, and all remote links use noopener.
    
        
    

        
    
          
    
            
          
    
          
    Headers
    
          
    When served by server.js, responses include CSP and standard browser security headers. Static hosting uses a CSP meta fallback.
